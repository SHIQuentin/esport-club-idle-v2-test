# Esport Club Idle V2 — version Web de test

Version jouable d'Esport Club Idle V2 (Godot 4.4.1, rendu Compatibility, WebGL 2, sans multithreading),
publiée avec GitHub Pages : https://shiquentin.github.io/esport-club-idle-v2-test/

Ce dépôt ne contient que les fichiers compilés de l'export Web. Comme tout site public, ces fichiers
(et les ressources du jeu qu'ils embarquent) sont téléchargeables par les visiteurs.

La progression est enregistrée dans le stockage du navigateur (IndexedDB) : elle est propre à chaque
navigateur et peut être effacée par celui-ci (par exemple par Safari après une longue période sans visite).
